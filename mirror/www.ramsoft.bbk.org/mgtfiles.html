Last updated: November 19th 1998

Welcome! Here is a part of our DISCiPLE/+D disks collection, so you can now start enjoying your Spectrum for real thanks to the wonderful MGT disk systems. The disks contain games, demos and utilities, all converted to work on disk. For example, you will be able to play multiload games in full comfort with the levels being loaded from disk in just one second. Some of them have also special patches from us, such as trainers, bugfixes and so on. There are special conversions of the most common utilities, and custom tools designed for the disk drive system. Feel all the power of working with disks, and you will never be able to go back to tapes!

WARNING: It is not advisable to download RAR files with Netscape Navigator/Communicator, since you may get them corrupted sometimes.

Note: the disk images are in .MGT format, which is supported by the latest versions of some emulators such as X128 v0.92. We wish to develop some tools to handle the various disk formats around, with the ability to read/write real floppy disks.
The MGT format is a raw dump of the disk (80 track of 10 sectors each) following the common PC layout: track-0/side-0, track-0/side-1, track-1/side-0, track-1/side-1, ... (which is not the DISCiPLE/+D way of handling disks, by the way).

Note: the archives are compressed with the RAR utility, which is more efficient than ZIP or ARJ. Get RAR v2.00 or above to extract the files.

How to use DISCiPLE/+D

There are several new BASIC commands made available by the disk BIOS to let you work with the disks in the same way as you do with tapes. We strongly recommend you to read our DISCiPLE/+D technical guide, where you will find almost everything about these interfaces, from the hardware secrets to an exhaustive manual for GDOS, G+DOS and UNIDOS.
 
Click here to DOWNLOAD DISCiPLE/+D GUIDE

Getting started:

  • Boot the system entering RUN after the machine reset. It will look for the DOS file called "sys*" or "+sys*". Most of the disks in this page contain at least one system file. There are several system versions, see below for a brief guide.
  • Use CAT 1 (or any drive number) to show the disk directory.
  • Enter LOAD d1;"filename" (or LOAD pN, where N is the program number) to load a BASIC program. You can use also CODE, SCREEN$ and DATA in the usual way.

Quick guide to the system files

There are several versions of the system file, some of them are official while others are nice hacks. This is a brief description of what you can find around:
 
  • System 3a: The first release for ROM3. Recommended when the others fail. Official.
  • System 3b: The most widespread, very compatible. Official.
  • System 3d: The latest official version, very advanced. Includes many of the newest features of the PlusD system, but the network doesn't work and some m/c loaders crash with it. Other programs require it, instead. Official.
  • System 3b+: A nice hack. From the snapshot menu, press 1 to save the 48K snap to tape, 2 for a 128K snap, X to return to the program and SPACE breaks to BASIC. My favourite one!
  • System Genie: The DISCiPLE porting of the famous debugger for the Multiface. Invaluable for programmers!
  • System Infinity: Again, the conversion for DISCiPLE of the famous program (by Ramsoft).
  • System 3ST: Our special version which adds a key to the snapshot menu to rip the Soundtracker modules in memory and save them to disk. Use our Backtracker to decompile them.
  • System 3: There is another hack (with no special name) which saves the snapshots to disk in compressed form.
You can find the whole variety listed above into the disks of our collection. Nearly all of them contain at least a system file.
 

If you have lost your original boot disk and you can't use the disk system anymore, pick an installation program for your interface below. These programs run from tape and will install a copy of the operating system, so you will be able to create a new boot disk.

  • DISCiPLE GDOS 3B installation tape (TAP, 7K)
Once that the operating system has been loaded, format a new disk with FORMAT d1 and then save the system file with SAVE d1;"system 3b" CODE 0,6656 (valid for DISCiPLE only). Please read our DISCiPLE/+D guide, it contains lots of useful information that we cannot report here!
